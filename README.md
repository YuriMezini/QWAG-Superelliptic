# QWAG-Superelliptic
# QWAG Superelliptic Code Package

This repository contains SageMath code for computations with superelliptic curves, one-point algebraic geometry codes, and CSS quantum codes.

The main file is:

```text
Pacage-QWAG-Superelliptic.ipynb
```

The notebook contains SageMath pipelines for curves of the form

```text
X : y^m = f(x)
```

over finite fields. The main implementation focuses on the case

```text
m = 5, deg(f) = 7.
```

In this case, the genus is

```text
g = 12
```

and the pole semigroup at the point at infinity is generated by

```text
<5, 7>.
```

## Purpose

The package was developed for computational experiments connecting:

- superelliptic curves,
- one-point algebraic geometry codes,
- CSS quantum codes,
- degree-seven polynomial databases,
- Galois group data,
- and comparisons between weighted/natural and classical code constructions.

The input polynomials come from the AIMS7 database of degree-seven polynomials and Galois groups.

The related AIMS7 data repository is:

```text
https://github.com/YuriMezini/AIMS-7-data
```

## Main Mathematical Construction

For a superelliptic curve

```text
X : y^m = f(x)
```

the package constructs one-point algebraic geometry codes

```text
C_L(D, rP_infinity),
```

where:

- `D` is the sum of rational evaluation points,
- `P_infinity` is the point at infinity,
- `r` is the pole-order parameter.

The package then searches for nested AG-code pairs and applies the CSS construction to obtain quantum codes.

## Weighted/Natural Model

The weighted or natural model uses the pole order

```text
pole_order(x^i y^j) = i*m + j*deg(f).
```

For the main case `m = 5` and `deg(f) = 7`, this becomes

```text
pole_order(x^i y^j) = 5i + 7j.
```

This is the natural filtration coming from the superelliptic function field.

## Classical Comparison Model

The notebook also contains a classical total-degree comparison model using

```text
i + j.
```

However, the AG/CSS distance estimates are still computed using the actual pole orders on the superelliptic function field.

This allows the classical model to be used as a comparison without replacing the true pole-order geometry.

## CSS Search

The package searches along the saturated CSS line

```text
r1 + r2 = N + 2g - 2,
```

where:

- `N` is the number of rational evaluation points,
- `g` is the genus,
- `r1` and `r2` are the AG-code pole-order parameters.

This avoids the trivial choice that forces designed quantum distance equal to 1.

The search chooses parameters by maximizing the finite-code score

```text
k_Q * d_Q,
```

where:

- `k_Q` is the quantum dimension,
- `d_Q` is the designed quantum distance bound.

## Main Features

The notebook includes SageMath routines for:

- checking superelliptic curves over finite fields,
- computing affine rational points,
- constructing Riemann-Roch bases using pole orders,
- building one-point AG codes,
- selecting nested AG-code pairs,
- constructing CSS quantum-code parameters,
- comparing weighted/natural and classical constructions,
- running experiments over finite fields such as GF(11), GF(31), and GF(61),
- saving computed tables as CSV files.

## Output Files

Depending on the run, the notebook can produce files such as:

These files record the computed AG/CSS code parameters for selected finite fields and model choices.

## How to Run

Open the notebook with SageMath/Jupyter:

```bash
sage -n jupyter
```

Then open:

```text
Pacage-QWAG-Superelliptic.ipynb
```

If the notebook code is separated into `.sage` scripts, example runs include:

```bash
sage run_q31.sage
sage run_q11.sage
sage run_q61.sage
```
